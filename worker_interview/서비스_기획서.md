# 캐스팅 캘린더 서비스 기획서

## 1. 서비스 개요

**캐스팅 캘린더**는 배우·모델·크리에이터가 자신의 프로필, 일정, 희망 조건을 한 번 등록하면 지원 가능한 캐스팅 공고를 우선순위로 추천하고, 지원 마감과 촬영 일정을 한곳에서 관리할 수 있게 하는 개인화 캐스팅 관리 서비스다.

목업의 핵심 화면은 사용자의 오늘 할 일과 매칭 공고를 보여주는 대시보드다. 서비스는 단순 공고 탐색을 넘어, “내가 실제로 지원할 수 있는 공고”를 빠르게 판단하도록 돕는 것을 목표로 한다.

## 2. 문제 정의

배우·모델은 여러 채널에 흩어진 공고를 직접 확인하고, 자신의 신체 정보·경력·가능 지역·출연 가능 일정·희망 페이를 매번 대조해야 한다. 이 과정에서 다음과 같은 문제가 생긴다.

- 조건에 맞지 않는 공고까지 검토하느라 시간이 많이 든다.
- 일정 충돌 또는 마감일을 놓쳐 지원 기회를 잃는다.
- 프로필과 사진을 반복 제출해야 한다.
- 지원한 공고와 촬영·오디션 일정을 분리해 관리하게 된다.

## 3. 목표와 핵심 가치

서비스의 목표는 사용자가 매일 대시보드에서 **지금 지원할 수 있는 좋은 기회**와 **놓치면 안 되는 일정**을 즉시 확인하게 만드는 것이다.

- 사용자: 조건·일정에 맞는 공고를 빠르게 찾고 지원한다.
- 캐스팅 담당자: 조건이 명확하고 최신 프로필을 가진 인재를 효율적으로 찾는다.
- 서비스: 조건 기반 매칭과 일정 연동으로 탐색부터 지원까지의 이탈을 줄인다.

## 4. 주요 사용자

### 1차 사용자: 배우·모델

- 광고, 뮤직비디오, 독립영화, 브랜드 콘텐츠 등의 캐스팅 공고를 찾는다.
- 활동 지역, 신체 조건, 언어, 촬영 가능 여부, 선호 일정과 최소 페이 기준이 있다.
- 여러 공고를 비교하고, 지원 마감 및 오디션·촬영 일정을 관리해야 한다.

### 2차 사용자: 캐스팅 담당자·제작사

- 역할별 필수 조건과 촬영 일정을 입력해 공고를 등록한다.
- 조건에 맞는 지원자 후보를 빠르게 검토하고 싶어 한다.

## 5. 핵심 사용자 흐름

1. 사용자는 기본 프로필과 대표·추가 사진을 등록한다.
2. 신체 정보, 경력, 언어, 활동 지역, 외부 촬영 가능 여부를 입력한다.
3. 가능 요일, 캘린더 일정, 근무 불가일, 최소 페이 등의 희망 조건을 설정한다.
4. 시스템은 공고의 조건과 사용자 정보·일정을 비교해 매칭 점수와 추천 공고를 만든다.
5. 사용자는 대시보드에서 추천 공고, 마감 임박 공고, 이번 주 일정을 확인한다.
6. 공고를 저장하거나 지원하고, 지원 마감·오디션·촬영 일정을 캘린더에서 관리한다.

## 6. MVP 기능 정의

| 영역 | 기능 | 사용자 가치 |
| --- | --- | --- |
| 프로필 | 대표 이미지, 추가 사진, 신체 정보, 경력, 연락처, SNS, 언어 입력 | 반복 지원에 필요한 기본 정보를 한 번에 관리 |
| 활동 조건 | 가능 요일, 외부 촬영 가능 여부, 최소 페이, 근무 불가일 설정 | 실제 지원 가능 공고만 추천받음 |
| 공고 매칭 | 연령대·지역·촬영 유형·조건 일치도를 기반으로 공고 추천 | 탐색 시간을 줄이고 지원 우선순위를 판단 |
| 공고 탐색 | 추천 공고 카드, 상세 보기, 저장, 전체 공고 보기 | 관심 기회를 비교·보관 |
| 일정 관리 | 주간 캘린더, 지원 마감·오디션·촬영 일정 표시 | 마감과 일정 충돌을 예방 |
| 알림 | 마감 임박, 새 매칭 공고, 일정 리마인드 | 중요한 기회를 놓치지 않음 |

## 7. 대시보드 구성

### 상단: 오늘의 상태

- 인사말과 날짜, 알림, 사용자 아바타를 제공한다.
- 사용자가 서비스에 접속했을 때 가장 먼저 현재 할 일을 인식하게 한다.

### 내 모델 프로필 카드

- 이름, 직군(배우/모델), 연령대, 키·몸무게, 활동 지역, 사용 언어, 외부 촬영·주말 가능 여부를 요약한다.
- ‘프로필 수정’으로 상세 입력 모달을 연다.

### 이번 주 매칭 공고

- 조건 일치도가 높은 공고 수와 진행률 바를 보여준다.
- 예: 12건, 프로필 및 조건 70% 이상 일치.
- 수치는 사용자가 프로필을 더 완성하거나 조건을 조정할 동기를 제공한다.

### 오늘의 맞춤 공고

- 회사명, 역할/프로젝트명, 조건 태그, 지원 마감일을 카드로 노출한다.
- 저장 버튼으로 관심 공고를 즉시 보관한다.
- 마감이 가까운 공고는 D-day를 강조한다.

### 이번 주 일정

- 오디션, 프로필 촬영, 지원 마감 등 행동이 필요한 일정을 주간 단위로 표시한다.
- 일정이 있는 날짜와 오늘을 시각적으로 구분한다.

### 매칭 설정

- 캘린더상 일정 자동 제외, 주말 가능 공고 우선 같은 현재 설정을 요약한다.
- 사용자는 추천 결과가 왜 달라지는지 이해하고 바로 수정할 수 있다.

## 8. 매칭 로직 초안

필수 조건을 우선 통과시키고, 이후 가중치 기반으로 추천 순위를 정한다.

| 구분 | 평가 항목 | 처리 방식 |
| --- | --- | --- |
| 필수 필터 | 성별/연령대, 지역, 촬영 가능일, 필수 신체 조건, 촬영 유형 | 불일치 시 추천 제외 또는 낮은 우선순위 |
| 가중 점수 | 프로필 완성도, 언어, 경력, 희망 페이, 선호 요일, 외부 촬영 가능 여부 | 일치 항목별 점수 합산 |
| 일정 검증 | 지원 마감, 오디션·촬영일과 캘린더 일정 충돌 | 충돌 공고 경고 또는 자동 제외 |
| 우선 노출 | 마감 임박, 높은 일치도, 새로 등록된 공고 | 사용자 행동을 유도하는 순서로 정렬 |

초기 MVP에서는 사용자가 이해하기 쉬운 조건 매칭 점수를 제공하고, 이후 지원·저장·열람 데이터를 반영해 개인화 정확도를 높인다.

## 9. 성공 지표

- 프로필 완성률: 가입 후 필수 프로필을 완료한 사용자 비율
- 매칭 공고 열람률: 추천 공고 카드 클릭 비율
- 저장률 및 지원 전환율: 열람 공고 대비 저장·지원 비율
- 마감 전 지원률: 마감 임박 공고를 제때 지원한 비율
- 일정 충돌 감소율: 일정 확인 후 취소·미응답으로 이어지는 비율의 변화
- 재방문율: 주간 대시보드 방문 사용자 비율

## 10. MVP 출시 범위와 다음 단계

### MVP

- 개인 프로필 및 사진 등록
- 조건·가용 일정 설정
- 조건 기반 공고 추천 및 저장
- 마감·오디션·촬영 일정이 보이는 주간 캘린더
- 기본 알림

### 고도화

- 공고별 원클릭 지원 및 포트폴리오 자동 첨부
- 외부 캘린더 연동과 충돌 자동 탐지
- 지원 상태 파이프라인(저장, 지원, 검토, 오디션, 확정, 종료)
- 캐스팅 담당자용 공고 등록·지원자 비교·메시지 기능
- 사용자 행동 데이터를 활용한 개인화 추천

## 다음 화면 후보 — 문서는 구현 착수 시 화면별로 작성

- **구인보드 트랙(1차)**: 로그인·가입 → 지원자 검토(Buyer — 공고 상세 Buyer 뷰: 충원 게이지·Standby 목록·D-day 운영 프리뷰) → 프로모터 마이(응답 인박스·지원 타임라인·**확정 근무·지원 마감 월 캘린더**(가용일정 캘린더 컴포넌트 재사용)·Grade 카드·**신규 공고 알림 옵트인 설정**) + 프로필 등록 사다리·가용일정 캘린더
- **행사 방(Event Room)**: Booking 확정 시 자동 개설 — Buyer·Leader 공지 + 워커 양방향(현장 질문·불만). 기획서 §14.2·§17, worker_interview 단톡방 수용
- **행사&광고 트랙**: 광고 상세 · 광고 등록(Buyer)
- **계승 트랙**(구 IA에서 유지할 제품 코어 — 순서 미정): 팀 추천·Team Builder·Booking 요청(POST 팀 초안이 입구를 목업함), 당일 운영(출결·대체 투입·인시던트), 리뷰
- 트랙 간 순서와 슬라이스는 홈에서 이어지는 사용자 동선이 확정되는 대로 재정의한다.

## 유지되는 제외 결정

인앱 알림 센터 없음(알림톡+딥링크로 대체) · 운영자 콘솔 없음(파일럿은 수동 운영) · In-App **1:1** Chat 없음 — 확정 행사 전용 **행사 방은 채택**(화면 후보) · 정산 화면 없음(예상 금액 표시만 — **세전·3.3% 원천징수 고지 필수**, 기획서 §9) · 공고 스크랩 없음(원터치 지원·철회가 대체).

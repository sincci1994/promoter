# MVP 화면 목록

> Version 0.4 (2026-08-09) — **IA 방향 전환**: 역할별 대시보드 우선 구조(A*/B*/P*/L* 27개 화면)를 폐기하고, **공개 구인보드 중심 양방향 IA**(참고: 사람인·알바몬·잡코리아 메인)로 재구성한다. 내부 홈이 구인공고와 행사&광고를 한 화면에 노출하고, Worker의 지원과 Buyer의 모집이 같은 관문을 공유한다. 이전 화면 정의는 이 시점에 삭제 — git 히스토리(커밋 `9f546a2` 시점) 참조.
> 기준 문서: [기획서 §26](../../README.md), [도메인 모델](../domain/02-domain-model.md) — 도메인(D1~D6)은 그대로 유효. [User Flow](user-flows.md)는 구 IA 기준이라 개정 대상.
> **용도**: 화면 생성·구현 시 해당 화면 파일 + [공통 규약](screens/_common.md) 2개를 함께 입력한다. 정책 미확정 값은 `[정책]` 표기.

## 다음 화면 후보 — 문서는 구현 착수 시 화면별로 작성

- **구인보드 트랙(1차)**: 로그인·가입 → 지원자 검토(Buyer — 공고 상세 Buyer 뷰: 충원 게이지·Standby 목록·D-day 운영 프리뷰) → 프로모터 마이(응답 인박스·지원 타임라인·월 요약·Grade 카드) + 프로필 등록 사다리·가용일정 캘린더
- **행사&광고 트랙**: 광고 상세 · 광고 등록(Buyer)
- **계승 트랙**(구 IA에서 유지할 제품 코어 — 순서 미정): 팀 추천·Team Builder·Booking 요청(POST 팀 초안이 입구를 목업함), 당일 운영(출결·대체 투입·인시던트), 리뷰
- 트랙 간 순서와 슬라이스는 홈에서 이어지는 사용자 동선이 확정되는 대로 재정의한다.

# JOB. 공고 상세 — 원터치 지원

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> 공용(지원은 Worker) · 반응형 · 라이트 테마 · `/jobs/[id]` · 진입: 홈 공고 카드·마감 임박 카드
> **상태: 목업 구현됨(2026-08-09)** — `src/app/jobs/[id]/page.tsx` + `src/components/jobs/apply-dock.tsx`(지원 상태는 클라이언트 로컬 — 실 API 교체 지점)

**목적**: "지원하기 너무 편한데?"의 본체. 지원서가 없다는 도메인 사실(Application 입력 = worker+role뿐)을 그대로 화면화 — 마찰은 입력에서 제거하고, 신중함은 제거 불가능한 정보 3개(언제·어디·얼마)로 담보한다.

- **레이아웃**: 본문 2/3 + 지원 독(데스크탑 sticky 우측 레일 / 모바일 하단 고정 바).
  ① 헤더 카드: 배지(유형·급구·신규·**정원 충족 · 대기 지원**)·D-day/마감 카운트다운, 행사명·업체, 일시·장소·역할 n명·모집(잔여 green / Standby amber + "자리가 나면 승인될 수 있어요" 안내)
  ② **단가 카드**: 내 단가 대형 표기 + `P2 기준` + **동결 고지**("지금 보신 금액이 지원 기록에 남고, 승인 시점 금액으로 동결됩니다" — displayed_amount의 사용자 언어) + **P1~P4 기본 단가 표**(내 등급 행 하이라이트, "좋은 근무 이력이 등급 산정에 반영" — 등록 동기 편재). 비로그인 변형: "가입하면 내 등급 단가로 보여요"(목업은 로그인 고정)
  ③ 근무 안내: 상세 업무·집합·복장은 "확정 후 플랫폼 안내" — 연락처 비공개 원칙(§14) 준수 문구
  ④ **이 행사의 다른 역할**(있을 때): 역할·단가·잔여 행 + "한 역할이 먼저 승인되면 나머지 지원은 자동 마감"(I10·OTHER_ROLE_APPROVED)
  ⑤ 지원 전에 알아두세요: 사전 동의·철회 가능·겹침은 승인 시 확인 — 3줄
- **지원 시트**(모바일 바텀시트/데스크탑 중앙 하단, 입력 필드 0·체크박스 0):
  - **첫 지원만 교육적 풀 시트 1회**(localStorage 플래그): "Buyer에게 이렇게 보여요" 프로필 미리보기(아바타·등급·지역·완료 수·태그) + "지원은 사전 동의 — 승인되면 바로 확정" 안내 + 요건 충족 체크(green)
  - **이후 축약 시트**: 3줄 요약(일시·장소·역할+단가) + 동결 고지 + 버튼 1개 — 목표 2초
  - **시간 겹침 소프트 경고**(amber, 지원은 막지 않음 — I6 하드 검사는 승인 시): 확정 근무 라벨 병기
  - **Standby 변형**: 버튼부터 "대기 지원하기"(즉시 승인 기대 차단), 접수 후 배지 "대기 지원 접수됨"
- **지원 후**: 시트 닫힘 + **undo 토스트**(6초, "지원 완료 — 검토 대기 [철회]") + 지원 독이 amber 배지 + 철회 버튼으로 반전. 철회(Open→Withdrawn) 즉시 원복
- **데이터**: 공고(home-content), mock 세션(등급·확정 근무·프로필). 지원 상태는 컴포넌트 로컬(새로고침 시 초기화 — 목업 명시)
- **정책**: 재지원 제한·지원 만료 기한·행사당 지원 상한 `[정책]` — 문구는 보수적으로만. 표시가 하락 시 재확인 `[정책]` 미구현

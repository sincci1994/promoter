# P4. 요청 목록

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Worker · 모바일 · `/p/requests` · 진입: 탭 바, 알림 랜딩(복수 요청 시)

**목적**: 응답해야 할 요청과 지난 요청 이력을 관리한다.

- **레이아웃**: 탭 2개 — **응답 대기**(카드: 행사명·브랜드·일시·장소(지역 수준)·Role·단가·카운트다운, Emergency는 red 테두리+프리미엄 강조, 임박순 정렬) / **지난 요청**(거절·만료·철회 — 상태 배지, 흐린 처리).
- **데이터**: Assignment(Requested / 종결 이력), PriceSnapshot 요약.
- **상태 변형**: 응답 대기 없음 빈 상태. 만료 임박(1시간 미만) red.
- **액션**: 카드 → [P5].

# A3. Worker 온보딩

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Worker · 모바일 · `/onboarding/worker` · 진입: [A2]에서 Worker 선택

**목적**: 추천에 노출될 수 있는 최소 프로필을 만든다. 사진 기반 인력 선정이 이 시장의 핵심 행위이므로 사진·포트폴리오가 중심이다.

- **레이아웃**: 4단계 스텝퍼. ① 기본 정보(이름/성별/생년/활동 지역 복수 선택) ② **프로필 사진 + 포트폴리오 업로드**(카메라/갤러리, 업로드 시 클라이언트 리사이즈, 대표 1 + 추가 n장, 드래그 정렬) ③ 자가신고 skill 태그(칩 다중 선택: 언어/MC/Product Demo/VIP 등) + 선호 행사 유형 ④ 완료 화면 — 초기 등급 P1 부여 안내 `[정책]`, 가용일정 등록 유도 버튼([P3]), **홈 화면에 추가(PWA 설치) 안내 카드**(iOS: 공유→홈 화면에 추가 일러스트).
- **데이터**: WorkerProfile 생성, GradeHistory 초기 행.
- **상태 변형**: 업로드 실패 재시도, 단계 중단 후 재진입 시 이어서 작성.
- **주의**: 자가신고 태그와 검증 자격(Certification)의 구분을 카피로 명시 — "인증 배지는 플랫폼 검증 후 부여됩니다"(D4).

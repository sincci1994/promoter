- **레이아웃**: ① 상태 타임라인(수락→확정→D-3 확정→D-1 확인→근무→완료 — 현재 단계 강조) ② **행사 안내 카드**(§17): 집합 시간·장소(지도 링크), 복장, 준비물, Event Brief 텍스트, 사전 교육 안내 ③ 금액 카드(동결 내역 재표시) ④ **D-3/D-1 확인 카드**(해당 시점에만): "행사가 3일 남았습니다 — [참여 확정] [참여 불가]" / D-1: "[최종 확인]" ⑤ 당일 카드: "집합 후 리더에게 체크인하세요" ⑥ 하단 링크: 취소 요청.
- **데이터**: Assignment(Accepted/Confirmed), PriceSnapshot, Event 안내(§17 콘텐츠), Attendance Risk 플래그.
- **상태 변형**: Risk 상태(미확인 시 amber 배너 "확인이 필요해요"), 당일(체크인 안내 강조), 완료 후(실근무 시간·리뷰 유도 → [P8]), NoShow 처리됨(red 안내 + 이의는 고객센터 `[정책]`).
- **액션 → 전이**: D-3 참여 확정/D-1 최종 확인 → Risk 플래그 해제. 참여 불가/취소 요청(다이얼로그 — 취소 정책 `[정책]` 고지, 임박 취소 경고) {Accepted|Confirmed→Cancelled} → Replacement 트리거 가능.

# P3. 가용일정

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Worker · 모바일 · `/p/availability` · 진입: [P1] 유도, [A3] 완료 버튼

**목적**: 추천 대상이 되기 위한 가용일정을 등록한다.

- **레이아웃**: 월 캘린더(등록일 dot 표시) + 날짜 탭 시 하단 시트: 시간대 슬롯 추가/삭제(시작–종료), 종일 토글. 상단에 **긴급 호출 가능(Emergency) 스위치** — 켜면 긴급 대체 요청 수신 대상이 된다는 설명. 안내 배너: "가용일정은 참고 정보입니다. 등록해도 예약이 자동 확정되지 않아요"(A2 — 예약 상태를 미러링하지 않음).
- **데이터**: AvailabilitySlot CRUD(date/time range, emergency_flag).
- **상태 변형**: 빈 캘린더 첫 등록 가이드.

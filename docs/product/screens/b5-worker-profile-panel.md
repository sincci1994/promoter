# B5. Worker 프로필 상세 (Buyer 뷰)

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Buyer · 데스크탑 · [B4]/[B7]에서 여는 사이드 패널 · 진입: 자리 카드·후보·Assignment 행·지원자 행([B7]/[B4], D6) 클릭

**목적**: 후보 한 명을 사진·경력·평가로 판단한다.

- **레이아웃**: 우측 슬라이드 패널 — 상단 포트폴리오 갤러리(대표 사진 크게, 썸네일 스트립), 이름·등급 배지·공개 평점(4.8), **검증 자격 배지 vs 자가신고 태그를 시각적으로 구분**(배지=체크 아이콘, 태그=회색 칩 — D4), 경력 요약(완료 행사 n회, 주요 행사 유형), 활동 지역, 이 Role 기준 예상 단가와 산출 내역(base + 자격 프리미엄 `[정책]`).
- **비공개**: 전화번호·이메일·SNS 없음(§14). Reliability 내부 점수 비노출(§20 — 공개 평점만).
- **지원자 검토 컨텍스트**(D6 — [B7] 지원자 행 진입): 헤더에 검토 대기 배지(amber)·지원 Role·지원 시각, 정원 충족 시 "대기(Standby)" 라벨 병기. 액션은 승인·반려로 바뀐다 — [B7] 행 버튼과 동일 트랜잭션(승인 확인 다이얼로그, 실패 시 "자리가 방금 충원되었습니다" 안내, 동결가 < 지원 시 표시가면 Worker 재확인 보류 변형 `[정책]`).
- **액션**: 컨텍스트에 따라 — 이 후보로 교체 / 팀에 담기 / 승인·반려(지원자 검토).

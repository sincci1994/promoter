**목적**: 양방향 플랫폼의 단일 관문. Worker는 공고를 탐색해 지원하고(pull), Buyer는 행사·광고를 노출하고 인력을 모집한다. 인앱 알림센터가 없는 결정(알림톡 대체)에 따라 **홈이 로그인 Worker의 상태 표면(알림센터 역할)을 겸한다**. 참고 모델: 사람인·알바몬·잡코리아 메인.

- **레이아웃**(위→아래):
  ① **공용 헤더**(`site-chrome.tsx` — 랜딩과 공유, 앱에서는 sticky bg-card / 랜딩에서는 transparent): 워드마크 · GNB(**소개**(→ 랜딩 `/`)/공고(활성)/행사·광고/기업 서비스) · 로그인 · **공고 등록**(primary → `/post`)
  ② 검색 히어로: 현황 한 줄(주차·모집 중 n건·이번 주 시작 n건·**활동 프로모터 n명·재의뢰율 n%**) + 검색바 + 퀵필터 칩
  ③ **워커 상태 스트립**(로그인 시, `dark` 스코프 카드): 응답 필요 n(카운트다운, amber 링) · 검토 중 · 대기 · 이번 주 확정 — 각각 마이 딥링크(예정)
  ④ **행사 & 광고**: 가로 스냅 캐러셀, 유료 광고 "AD" 배지
  ⑤ **마감 임박 · 급구**: 가로 카드, 카운트다운(1시간 미만 red-600/이상 amber-700)
  ⑥ **이번 주말 한눈에**: 주말 시작 공고 스트립 + 가용일정 등록자 개인화 캡션("토요일이 가용일로 등록돼 있어요")
  ⑦ **지도 구인맵**: 자체 제작 수도권 개략 SVG(한강 실루엣) + 거점 핀(공고 수 배지, 탭=지역 필터) — 지도 서비스 이미지 미사용(약관). 모바일은 같은 버튼을 칩 행으로. 수도권 외 거점은 각주
  ⑧ **신규 공고**: **주간 날짜 스트립**(14일, 요일·일자·공고 수, 주말 orange, 탭=날짜 필터) + 유형 탭 + 그리드. 날짜·유형·지역 3필터 AND 결합, 활성 시 "필터 초기화" 노출, 결과 없음 빈 상태. 카드 단가에 **내 등급 기준 배지**(`P2 기준`)
  ⑨ 양방향 CTA: Worker 다크 패널 + **Buyer 미니폼**(유형·일시·인원 3필드 → 입력 즉시 "가용 등록 후보 n명 · ₩X부터" 실계산 → `/post` 값 이관)
  ⑩ **3중 안전망**: D-3·D-1 자동 재확인·백업 탐색 / Standby 풀 / 긴급 대체(성공=현장 도착) — 정의 기반 카피

# B3. 역할 구성

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Buyer · 데스크탑 · `/buyer/events/[id]/roles` · 진입: [B2] 직후, [B7] (첫 요청 전까지만 편집 가능 — I7)

**목적**: 행사에 필요한 Role과 요구조건을 정의한다. 추천 품질은 여기 입력이 결정한다.

- **레이아웃**: Role 카드 리스트(추가/삭제/복제) + 우측 요약(총 인원, Role 수). 카드 필드: 역할 이름, 종류(프로모터/**리더** — 리더 Role은 행사당 1개 제한 I9, 이미 있으면 선택 비활성), 인원수(required_count), 최소 등급(P1~P4 선택), **검증 자격 요구**(자격 선택 + 최소 레벨 + 필수/우대 토글), 소프트 조건 태그(자유 칩 — 자가신고 태그 매칭용).
- **데이터**: EventRole CRUD.
- **상태 변형**: 첫 Booking 요청 이후 재진입 시 전체 읽기 전용 + "요청 후에는 요구조건을 변경할 수 없습니다(정원 조정은 미충원 마감으로)" 배너.
- **액션**: 구성 완료·추천 받기 → {Event: Draft→TeamBuilding} + 추천 실행 → [B4].
- **정책**: 자격 프리미엄 단가 표시는 `[정책]`.

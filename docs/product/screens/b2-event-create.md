# B2. 행사 생성

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Buyer · 데스크탑 · `/buyer/events/new` · 진입: [B1]

**목적**: 행사 기본 정보를 입력해 Event를 만든다.

- **레이아웃**: 좌측 폼(행사명/행사 유형 선택/브랜드/날짜/시작–종료 시간/장소 주소+상세) + 우측 안내 패널(다음 단계 미리보기).
- **제약 표기**: **단일 근무 시간대 전제(A7)** — "여러 날짜·교대가 있는 행사는 날짜별로 각각 생성해 주세요" 안내 문구 + 날짜 복수 선택 UI를 두지 않는다.
- **데이터**: Event 생성 {생성→Draft}.
- **액션**: 저장 후 계속 → [B3]. 임시 저장(Draft 유지) → [B1].

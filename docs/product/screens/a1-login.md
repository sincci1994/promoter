# A1. 로그인

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> 공통 · 양쪽 · `/login` · 진입: 미인증 접근 전부, 알림 링크의 세션 만료 시

**목적**: 이메일 또는 카카오로 로그인한다.

- **레이아웃**: 중앙 카드 1장 — 로고, 카카오로 시작(노랑, 상단), 이메일+비밀번호 폼, 가입 링크.
- **데이터**: User(email, status).
- **상태 변형**: 로그인 실패 인라인 에러. 정지 계정(status) 안내 변형.
- **액션**: 로그인 성공 → 프로필 보유 여부로 분기(WorkerProfile→[P1], BuyerProfile→[B1], 둘 다 없으면→[A2]). 알림 딥링크로 왔다면 원래 목적지로.

# B6. Booking 요청 발송

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Buyer · 데스크탑 · `/buyer/events/[id]/request` · 진입: [B4] CTA

**목적**: 요청 내용을 최종 확인하고 발송한다. 발송 순간 가격이 동결되고 행사 조건이 잠긴다 — 이 화면의 역할은 그 두 가지를 명확히 고지하는 것.

- **레이아웃**: 주문 확인형 단일 컬럼 — ① 선택 인력 요약(Role별 리스트: 사진 소형+이름+단가) ② **가격 내역**(Assignment별 라인아이템: 기본 단가 × 시간, 자격 프리미엄, 행사 프리미엄, 고정수당 `[정책]` — 총액 강조) ③ 고지 박스 2개: "발송 시점 가격으로 동결됩니다(이후 정책 변경 무영향)", "**발송 후 행사 일시·장소·역할 조건은 변경할 수 없습니다**(I7) — 변경이 필요하면 취소 후 재요청" ④ 응답기한 안내(일반 24시간/임박 3시간 `[정책]`) ⑤ CTA "예약 요청 보내기".
- **데이터**: 발송 트랜잭션 — Booking 생성(I1), Assignment {Selected→Requested} × N, **PriceSnapshot 동결(I5)**, expires_at 설정, {Event: TeamBuilding→BookingPending}, Worker 알림 발송(outbox).
- **상태 변형**: 발송 중(이중 클릭 방지), 발송 성공 → [B7] 리다이렉트 + 성공 토스트.

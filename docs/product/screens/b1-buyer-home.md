# B1. Buyer 홈 — 행사 목록

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Buyer · 데스크탑 · `/buyer` · 진입: 로그인 후 기본, 전역 내비 "내 행사"

**목적**: 내 행사들의 상태와 충원 현황을 한눈에 보고, 주의가 필요한 행사(응답 대기·결원·확인 필요)로 바로 이동한다.

- **레이아웃**: 상단 헤더(새 행사 만들기 버튼 우측 고정) + 상태 필터 탭(전체/작성 중/팀 구성/응답 대기/확정/진행 중/완료/취소) + 행사 카드 그리드.
- **카드 구성**: 행사명·브랜드, 일시·장소, Event 상태 배지 + Booking 파생 상태 배지, **충원 게이지**(충원 n / 유효 정원 m — 충원 projection), 주의 플래그(만료 임박 요청 n건, D-1 미확인 n명, 결원 발생).
- **데이터**: Event, Booking(파생 상태), 충원 projection(role별 합산), Attendance Risk 수.
- **상태 변형**: 빈 상태(첫 행사 만들기 유도), 진행 중 행사는 카드가 [B8]로 직행.
- **액션**: 카드 → [B7]. 새 행사 → [B2].

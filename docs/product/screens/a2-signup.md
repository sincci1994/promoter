# A2. 가입·역할 선택

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> 공통 · 양쪽 · `/signup` · 진입: [A1] 가입 링크

**목적**: 계정 생성 후 시작 역할을 고른다. 역할은 배타가 아니다 — 한 User가 나중에 양쪽 프로필을 모두 가질 수 있다(D3).

- **레이아웃**: 1단계 계정 폼(이메일/비밀번호/휴대폰 — 휴대폰은 알림 수신용, 비공개), 2단계 선택 카드 2장: "행사 인력이 필요합니다"(Buyer→[A4]) / "행사에서 일하고 싶습니다"(Worker→[A3]).
- **데이터**: User 생성.
- **정책**: 휴대폰 본인인증 여부 `[정책]` — MVP는 SMS 수신 확인 수준.

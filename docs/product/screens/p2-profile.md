# P2. 프로필 관리

> [MVP 화면 목록](../mvp-screens.md) 소속 — 디자인 생성 시 [공통 규약](_common.md)과 함께 입력
> Worker · 모바일 · `/p/profile` · 진입: 탭 바, [A3] 이후 편집

**목적**: 추천 노출의 원료인 프로필을 관리하고, 내 성장(등급·경력)을 확인한다.

- **레이아웃**: ① 헤더 — 대표 사진, 이름, **등급 배지(P1~P4) + 공개 평점**, 완료 행사 n회 ② 포트폴리오 그리드(추가/삭제/대표 지정, 업로드 시 클라이언트 리사이즈) ③ 자가신고 태그 편집(칩) + 선호 행사 유형 + 활동 지역 ④ **검증 자격 섹션** — 보유 Certification 배지(Leader L1~L3, 검증 Skill), "자격은 플랫폼 검증 후 부여됩니다" ⑤ 등급 이력 — GradeHistory 타임라인(등급·적용 기간, 산정 근거 요약 `[정책]`) ⑥ 계정 설정(휴대폰 변경 — 알림 수신처).
- **데이터**: WorkerProfile, GradeHistory, WorkerCertification, 공개 평점(Review 집계), Career(Completed 집계).
- **비노출**: Reliability 내부 점수(§20 — 운영용, 본인에게도 비공개).
